- **Ошибки загрузки** (E) — фронт больше не маскирует 5xx под пустой экран; добавлены `isLoadingError`

  не молчат больше. `useLogout` очищает кеш, refresh-cookie отзывается правильно.

## Как это делалось

Параллельные браузерные прогоны 4 сценариев (learner A-1…A-11, org O-1…O-9, admin AD-1…AD-8,
exercises X-1…X-12) против реального `https://sellevate.site` в Chrome, + статические кодовые
аудиты по классам дефектов (contract, null-safety, error-masking, silent-writes, tenancy).

Каждая находка → отдельный коммит с `fix:` префиксом, на английском (проектное соглашение).
Каждый блок → документирование в docs/AUDIT_*.md параллельно. Интеграционные тесты tenancy
прогнаны на реальном локальном Postgres (4/4 passed). Ничего не запушено, сервера не трогали.

~70 коммитов, 15+ агентов запущено параллельно (часть убиты платформенными лимитами,
их работа спасена и слита). Ревью ночных фиксов независимо в docs/AUDIT_NIGHT_REVIEW.md —
вердикт REQUEST CHANGES (R-1…R-22), из них R-17 блокирует деплой, остальные требуют проверки.

Путь: `origin/main` → локальный `main` (на ~70 коммитов) → _ваши действия_ → пуш → редеплой →
Q-вопросы решены → следующий audit pass (если нужен).
